# Personal Portfolio Website

A responsive personal portfolio starter built with HTML and CSS.

## Before publishing
1. Rename this folder to `yourlastname-project-1` (replace with your actual surname).
2. Open `index.html` and replace every placeholder: Your Name, course/year, school, hobbies, email, GitHub username, and initials.
3. Replace the initials block in the hero with your own profile photo if desired. Put the image in `assets/` and update the HTML.
4. Update the skills and sample projects so they accurately describe your experience.
5. Preview `index.html` in a browser.

## Folder structure
- `index.html` — page content
- `styles/style.css` — styling and responsive layout
- `assets/` — place your profile photo and other images here

## Git setup
Open a terminal in this project folder and run:

```bash
git init
git add index.html
git commit -m "Create portfolio page structure"
git add styles/style.css
git commit -m "Add base styles and typography"
git commit -am "Build responsive hero section"
git commit -am "Add about section"
git commit -am "Add skills section"
git commit -am "Create project showcase"
git commit -am "Add contact section and footer"
git commit -am "Improve mobile responsive layout"
git commit -am "Polish colors spacing and hover states"
git add README.md assets
git commit -m "Document project and organize assets"
```

These are example development milestones. For authentic progress history, make each commit after the corresponding change rather than creating all commits at once.

## GitHub and GitHub Pages
1. Create a new GitHub repository named `yourlastname-project-1`.
2. In the terminal, connect and push (replace the URL with your repository URL):

```bash
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/yourlastname-project-1.git
git push -u origin main
```

3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. Your website URL will usually be:
   `https://YOUR-USERNAME.github.io/yourlastname-project-1/`

Submit both the live Pages URL and repository URL through your instructor's Google Form. Do not submit until you have checked that the live site opens correctly.
